# Quiz Game Application

## SkillCraft Technology – Web Development Task 03

### 📌 Project Description
This project is an interactive Quiz Game Web Application developed using HTML, CSS, and JavaScript. The application presents multiple-choice questions to the user, collects answers, evaluates responses, and displays the final score at the end of the quiz.

The project demonstrates the use of DOM manipulation, event handling, and logical implementation in JavaScript.

---

### 🚀 Features
- Multiple-choice questions
- Dynamic question loading
- Score calculation
- Final result display
- Interactive and user-friendly interface
- Responsive layout design

---

### 🛠 Technologies Used
- HTML
- CSS
- JavaScript

---

### ▶ How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Select the correct answer for each question.
4. Click Next to move to the next question.
5. View your final score after completing the quiz.
